# 招商采购商机小程序农副产品发布机械设备发布信息发布类小程序二手交易转让收购平台

源码获取：ym7k.com/19825/

## ✅ 核心功能模块

### 1. 信息发布（平台核心）

四大信息类型：**供应、求购、转让、招商**

- 多级分类：农副产品、农业物资、工程机械、工业设备、五金、厂房土地、原材料、二手闲置等，后台可无限新增分类
- 发布表单：标题、图文 / 视频、价格（可填面议）、数量、产地、规格、有效期、所在地区、联系电话
- 支持图片、多图上传、视频上传，适合设备实拍、农产品实拍
- 发布前后台审核，违规信息驳回，防止垃圾广告

### 2. 小程序端浏览与筛选

- LBS 同城 / 按地区筛选商机，按行业分类、价格区间、发布时间排序
- 关键词搜索（设备型号、农产品名称）
- 信息详情、收藏、转发、私信 / 电话联系发布人
- 发布人主页：查看该商家全部供应 / 求购 / 转让信息
- 信息置顶、付费刷新（平台盈利点）

### 3. 用户与商家入驻

- 微信一键授权登录，手机号实名认证
- 个人发布 / 企业商家入驻，企业可上传营业执照审核
- 商家店铺主页、商家简介、主营品类、联系信息
- 会员套餐：会员可免费发布条数更多、置顶折扣、免审核优先通过

### 4. 二手转让 & 收购专区

- 二手机械设备、农机、工具、厂房设备转让
- 收购需求：回收原料、废旧设备、农副产品收购
- 区分：转让（卖家出货）、收购（买家收货），方便供需精准匹配

### 5. 招商专区

厂房出租、场地招商、项目招商、加盟招商、产业园招商，单独板块展示

### 6. 营销 & 变现模块

- 付费置顶、刷新信息、竞价排名
- 分销推广：分享商机邀请注册拿奖励
- 广告位：首页轮播、分类页广告，商家投放广告
- 会员套餐：限制免费发布条数，付费解锁更多发布额度
- 消息推送：商机匹配提醒、有人咨询、审核结果通知

### 7. 后台管理（FastAdmin）RBAC 权限

- 分类管理、标签管理、地区管理
- 信息审核、违规下架、举报处理
- 用户管理、商家资质审核、实名认证管理
- 广告管理、置顶套餐、会员价格配置
- 数据看板：发布总量、供应 / 求购统计、访问量、图表统计、导出报表
- 敏感词过滤、短信通知、OSS 存储

### 8. 沟通与线索

- 平台内置私信聊天（高级版）
- 一键拨号联系，保护隐私（可隐藏手机号）
- 咨询记录、留言板

## 🖥️ 部署环境

- PHP7.4，MySQL5.7/8.0，Nginx
- HBuilderX 打开 UniApp 源码，编译微信小程序，可选编译 H5
- 需要：百度 / 高德地图（地区定位）、短信、对象存储
